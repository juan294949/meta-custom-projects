## About these tools.

  Arm cross compiler: An ARM cross compiler is a toolchain used to compile source code (typically written in C or C++) into machine code that runs on ARM-based processors.

  GCC (gnu compiler collection): GCC (GNU Compiler Collection) is a collection of compilers for various programming languages, including C, C++, Objective-C, Fortran, Ada, Java, Go, D, and more. It also includes essential tools for compiling and linking code.

# Questions.

  Question: is arm cross compiler included with gcc?
  R: No, an ARM cross-compiler is typically not included with a standard GCC installation. You need to install a separate ARM cross-compiler toolchain to compile code for ARM targets. GCC itself is a compiler, and the ARM cross-compiler is a specific version of GCC that's configured to generate ARM machine code.
